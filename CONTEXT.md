## 1. Концепция и цели

**Sklad-CMS** — легковесный модульный eCommerce-движок и панель управления для оптовой торговли, B2B-каталогов сложной техники (погрузчики, складское оборудование, запчасти) и дилерских сетей.

### Ключевые преимущества:
- **Zero-Dependency / Чистый PHP 8.2+:** без тяжелых фреймворков (Laravel, Symfony, Bitrix). Быстрый отклик (TTFB ~15 мс), минимальное потребление RAM (2–4 МБ на запрос).
- **Высокая нагрузка и мульти-каталоги:** поддержка сотен категорий, тысяч параметров и фильтрации без деградации базы.
- **Готовая контейнеризация:** `docker-compose.yml` (PHP 8.2-FPM + Nginx Alpine + MySQL 8.0 + Redis).

## 3. База данных и архитектура

Схема БД консолидирована в [install/schema.sql](file:///C:/Users/aaami/.gemini/antigravity/scratch/admin-panel/install/schema.sql):
- **Пользователи и RBAC:** `users`, `roles`, `permissions` (поддержка прав: суперадмин, менеджер каталога, оператор заказов).
- **Каталог товаров:** `categories`, `products`, `product_attributes`, `attribute_values`, `product_images`.
- **B2B-клиенты и дилеры:** `dealers`, `price_groups`, `discounts` (индивидуальные колонки цен).
- **Заказы:** `orders`, `order_items`, `order_statuses`, `order_history`.
- **Настройки сайта:** `settings` (мульти-тенантность, контакты, реквизиты, параметры наценки).

## 5. Бэклог задач по разработке админ-панели (Roadmap)

1. **Панель управления (Admin UI & UX):**
   - Авторизация, сессии через `httpOnly` cookie, защита от CSRF / Brute-force.
   - Главный дашборд: сводка по заказам, новым дилерам, остаткам на складах, конверсии.
2. **Модуль каталога товаров:**
   - Быстрое редактирование цен и наличия прямо из таблицы (inline edit).
   - Генерация SEO-полей (ЧПУ, title, description, OpenGraph).
   - Пакетная загрузка изображений с автоматическим созданием WebP превью.
3. **Модуль заказов (B2B Order Flow):**
   - Формирование коммерческих предложений (PDF-генератор счёта/КП).
   - Смена статусов заказов с email/Telegram уведомлениями клиенту и менеджеру.
4. **Импорт / Экспорт:**
   - Потоковый парсинг прайс-листов Excel (XLSX/CSV) на 50 000+ позиций без превышения memory_limit.
   - REST API эндпоинты для обмена с 1С / МойСклад.

## 6. Правила разработки для агента

1. **Никакого оверинжиниринга (принцип Ponytail):** 
   - Не добавлять сторонние зависимости, если задачу можно решить стандартной библиотекой PHP (PDO, cURL, GD/Imagick, DOMDocument).
   - Код должен оставаться понятным, модульным и легко читаемым соло-разработчиком.
2. **Безопасность:**
   - Никаких сырых конкатенаций SQL — только подготовленные выражения PDO (`prepare` + `execute`).
   - Экранирование вывода через `htmlspecialchars()` в шаблонах.
3. **Строгая типизация:**
   - Все новые PHP-файлы начинаются с `declare(strict_types=1);`.
   - Явные типы аргументов и возвращаемых значений у всех методов.
4. **Git:**
   - Понятные коммиты на русском языке без подписей ИИ (`Co-Authored-By`).
